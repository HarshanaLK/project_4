# Synapse Collab

A production-style real-time collaborative code editor + whiteboard built as a portfolio project for software-engineering and full-stack roles.

## Stack

- Frontend: Next.js 16.3.8, React 19, TypeScript, Monaco Editor, STOMP WebSocket client
- Backend: Java 21, Spring Boot 4.1.0, Spring Security, Spring WebSocket/STOMP, Spring Data JPA
- Database: MySQL 8 + Flyway
- Auth: stateless JWT
- Deployment: Vercel for the Next.js frontend; any Java/JAR host for the Spring Boot API
- Containers: none required
